    "## 5. Define Instructor Effectiveness\n",
    "\n",
    "There is no predefined formula in the assignment, so we define a transparent composite score.\n",
    "\n",
    "### Proposed score\n",
    "\n",
    "After scaling each metric to a comparable 0–1 range:\n",
    "\n",
    "- Completion: **15%**\n",
    "- Dropout (reverse scored): **15%**\n",
    "- Score improvement: **15%**\n",
    "- Quiz score: **10%**\n",
    "- Watch time: **10%**\n",
    "- Assignment submission: **10%**\n",
    "- Forum activity: **5%**\n",
    "- Feedback score: **10%**\n",
    "- Feedback response rate: **10%**\n",
    "\n",
    "The weights emphasize learner outcomes while still including engagement and learner feedback.\n",
    "\n",
    "For dropout, lower is better, so it is converted to `1 - normalized_dropout`.\n",
    "\n",
    "Because score improvement and quiz score may have different scales, min-max normalization is applied to the observed dataset.\n"
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "f72b182c",
   "metadata": {},
   "outputs": [],
   "source": [
    "# Create normalized metrics\n",
    "score_cols = [\n",
    "    \"completion_rate\", \"dropout_rate\", \"avg_score_improvement\",\n",
    "    \"avg_quiz_score\", \"avg_watch_time\",\n",
    "    \"assignment_submission_rate\", \"forum_activity_rate\",\n",
    "    \"avg_feedback_score\", \"feedback_response_rate\"\n",
    "]\n",
    "\n",
    "def minmax(series):\n",
    "    lo = series.min()\n",
    "    hi = series.max()\n",
    "    if hi == lo:\n",
    "        return pd.Series(np.ones(len(series)) * 0.5, index=series.index)\n",
    "    return (series - lo) / (hi - lo)\n",
    "\n",
    "norm = pd.DataFrame(index=df.index)\n",
    "\n",
    "for col in score_cols:\n",
    "    norm[col] = minmax(df[col])\n",
    "\n",
    "# Reverse dropout: high value means better performance\n",
    "norm[\"dropout_good\"] = 1 - norm[\"dropout_rate\"]\n",
    "\n",
    "weights = {\n",
    "    \"completion_rate\": 0.15,\n",
    "    \"dropout_good\": 0.15,\n",
    "    \"avg_score_improvement\": 0.15,\n",
    "    \"avg_quiz_score\": 0.10,\n",
    "    \"avg_watch_time\": 0.10,\n",
    "    \"assignment_submission_rate\": 0.10,\n",
    "    \"forum_activity_rate\": 0.05,\n",
    "    \"avg_feedback_score\": 0.10,\n",
    "    \"feedback_response_rate\": 0.10\n",
    "}\n",
    "\n",
    "df[\"batch_effectiveness_score\"] = sum(\n",
    "    norm[col] * weight for col, weight in weights.items()\n",
    ")\n",
    "\n",
    "display(df[[\"instructor_id\", \"batch_id\", \"batch_effectiveness_score\"]].head())\n"

    "## 9. Mandatory Analysis Questions\n",
    "\n",
    "### 1. Which features most influenced instructor effectiveness, and why?\n",
    "\n",
    "The strongest influences should be identified from the coefficient/importance plot **after running the notebook**. Conceptually, completion, dropout, score improvement, and engagement measures are important because they directly reflect learner outcomes and participation.\n",
    "\n",
    "### 2. Which variables could be misleading or confounded?\n",
    "\n",
    "Potential confounders include course difficulty, learner ability, batch size, prior learner knowledge, course duration, assessment difficulty, and instructor-course matching. Feedback can also be biased by learner expectations or satisfaction with the course rather than teaching quality alone.\n",
    "\n",
    "### 3. How could this model fail in real-world usage?\n",
    "\n",
    "It may fail when the learner population changes, a new course is introduced, data is sparse, metrics are measured differently, or instructor effectiveness is influenced by factors absent from the dataset. Small numbers of batches can also make an instructor's average unstable.\n",
    "\n",
    "### 4. What additional data would improve the analysis?\n",
    "\n",
    "Useful additions include batch size, learner pre-test score, learner demographics in aggregated/privacy-safe form, course difficulty, instructor experience, attendance, live-session participation, assignment quality, assessment difficulty, course duration, and longitudinal learner outcomes.\n",
    "\n",
    "### 5. Should this model be used for instructor performance evaluation?\n",
    "\n",
    "**Not as a standalone decision tool.** It can support coaching and quality improvement, but it should not be used alone for hiring, firing, compensation, or punitive ranking. The model is based on observational learner data and may reflect course or learner differences rather than instructor ability.\n"
